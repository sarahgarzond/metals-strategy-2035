# 4. Metal Markets: Production & Form

The metal profiles apply the measurement rule from Chapter 3 one material at a time. Each profile states the commercial form a figure refers to, because ore, intermediate, refined metal and mill product answer different sourcing questions. Country rankings appear only where a dated dataset is in the source log. Nickel is first, because Table 2 is the only scale exhibit and the later metals are then set against that basket rather than against a repeated ladder of the same tonnes.
