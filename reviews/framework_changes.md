# Framework changes

## 2026-11-07 Data chain mapping in Chapter 3

Reason: The project instructions allow one short table showing how Supply, Trade, Demand and Outlook map onto Material, Product form, Application, Industry, Geography, Market size and Growth. The table makes that mapping explicit so later chapters do not mix a mine tonne, a mill product tonne and an industry revenue figure.

## 2026-11-07 Chapter 8 criteria named in Chapter 3

Reason: The project instructions allow naming the assessment criteria that Chapter 8 uses to integrate the four dimensions. The eight criteria are those already used in the project scoring note. No weights are recalculated in the prose, because application shipment shares were not supplied.

## 2026-11-07 Apparent consumption stated as a measurement rule

Reason: The team asked for production plus imports minus exports to be visible in Chapters 4 and 6. This does not add a dimension and does not rename Supply or Trade. It specifies how mill product availability is read inside those existing dimensions, and it records that the identity is not end use demand and not stainless melt. The formula is logged as AC_METHOD.
